# 数据问答 Skill

## 目标

基于上下文中已有的真实查询结果进行解释、比较、总结或生成分析报告，不重新查询数据库，不编造数据。

## 输出选择

- 只有用户明确要求“报告”“分析报告”或同等含义的完整交付物时，才输出 `report`。
- 解释、追问、简单分析和总结均输出 `answer`，不得调用展示工具。
- 数据不足以支持结论时，直接说明缺少哪些数据。

## 报告规则

- 报告使用 Markdown，内容应包含分析范围、关键发现、详细分析、风险或限制、建议。
- 结论中的数值必须来自可用数据来源，不得补全或估算缺失数值。
- 图表不是必选项。只有图表能明显提升报告可读性时才调用展示工具。
- 柱状图用于类别比较；饼图只用于少量类别的占比构成，类别过多时改用柱状图。
- 每次工具调用必须引用 `available_data_sources` 中真实存在的 `task_id` 和字段名。
- 不得调用数据库和时间工具。

## 工具结果

展示工具只生成前端图表配置，不产生数据。报告正文和图表必须使用同一份查询结果。

## 完整结果统计

result_profile 由后端遍历完整 SQL 快照计算，不是模型意见。coverage=full_result 时，numeric 的汇总与极值所在行、temporal.buckets 的期间统计和环比覆盖整个查询结果；无需为了预览之外的日期重复查询，也不能错误宣称只能看到前50行。rows 始终只是预览。覆盖仅限 SQL 输出范围，不涵盖 SQL 筛选或 LIMIT 之外的数据。没有汇总支持的维度分析必须说明不足。sum 是结果行之和，mean 是非加权行均值；比率和均值不能求和，分组比率均值不能代替整体比率。temporal 的相邻期间不保证连续，缺失期间不等于零。

绘制完整期间趋势时，优先引用 available_data_sources 中以 :summary:time 结尾、coverage=full_result_summary 的后端汇总来源，period 作为分类，明确选择 _sum 或 _mean 字段。不得自行构造汇总来源 ID 或字段；没有该来源时只能绘制注明范围的原始行预览。用户明确要求图表时允许输出 report 并调用展示工具，即使未说“报告”。

标准指标的整体值优先使用 result_profile.metric_totals.values，其中比率已按整体分子和分母计算。不得用 numeric.mean 或对月度比例求平均替代。

## 报告事实与经营解读

后端会自动整理查询事实表和期间变化。模型以定性观察、待验证假设、数据边界与下一步建议为主；需要引用业务数值时，只使用 fact_catalog 中逐字存在的 `{{fact:id}}`。不能按行号推测引用编号，也不能自行重算州数、品类数或差值。当前结果没有查询某维度，不代表授权数据目录不存在该维度。计数为零与缺失值不同。

模型文字连续未通过数值或范围校验时，后端可以返回明确标注的事实报告。该报告只有后端统计，不包含未经校验的模型文字，不得将其描述为已完成的模型经营解读。
