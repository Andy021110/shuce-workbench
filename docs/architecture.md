# 架构与实现

## 模块和数据流

前端使用 Vue 3、TypeScript 与 Vite。`App.vue` 负责登录、数据源和分析会话；独立组件承接经营首页、范围、结果、图表、报告、CSV 管理和实际调用记录。

后端以 FastAPI 提供接口，`AskDataService` 统一执行业务任务并维护会话上下文。数据来源为本地 CSV，经 DuckDB 注册与查询。结果快照按任务保存；完整行集用于分页、筛选、统计和导出，不把当前页面上的几行当作全量结果。

### 固定经营路径

`metric_registry.py` 和 `monthly_review.py` 定义指标和复盘步骤。月份与结构化范围经过校验后生成标准 SQL。适合确定性月度对比、量价构成、品类和配送下钻。此路径可以没有 Chat、Embedding、Rerank 或 MCP 执行。

### 自由问数路径

`QueryWorkflow` 使用 LangGraph 组织预处理、意图选择、字段检索、澄清和执行。Schema 检索组合 BM25、向量召回、RRF 和 Rerank；按请求权限裁剪可见数据。单数据库 Agent 通过本地 MCP 查询工具执行受限 SQL，必要时结构化修正。

工具权限来自后端 `AccessScope`，不能只依赖前端隐藏按钮。MCP 在本地进程内建立，未声称具备独立远程平台的租户、分布式治理或安全沙盒能力。

### 结果与报告

结果保留 SQL、行列、总量、口径、查询意图、分析范围、结果摘要和执行记录。`report_facts.py` 从已执行结果构建事实，校验生成报告的数字与引用范围。失败进入事实回退；人工补充仍保留原始依据，并独立标记编辑状态。

报告来源必须从当前用户、当前数据源允许的任务读取；客户端提交的任意行数据不能直接成为可信历史来源。手选六份但上下文只使用五份的已知问题仍在台账中。

## 状态和恢复

| 状态 | 保存位置 | 边界 |
|---|---|---|
| 登录令牌 | 后端内存、前端会话存储 | 服务重启后重新登录；演示身份体系 |
| 当前分析、历史结果与归档 | 内存与可配置 SQLite 归档 | 按用户与数据源隔离 |
| 结果完整行集 | 本地快照文件 | 需要保留对应快照文件 |
| 未发送问题和报告草稿 | 浏览器本地存储 | 当前浏览器、对应用户/来源/任务；不能替代服务端跨设备保存 |
| 未结束工作流与实时调用 | 进程内状态 | 重启后不能保证恢复任意中断点 |
| 已完成且采集过的调用摘要 | 对应结果记录 | 老记录未采集时是未知，不补造为零 |

停止页面等待只暂停等待/更新，不保证供应商请求已取消。页面说明与实际后端取消能力分别处理。

## 调用可观察性

`telemetry.py` 在实际模型和工具请求边界记录开始、完成和失败。运行中接口返回安全的记录快照，前端约每秒更新，短请求可能在两次刷新间结束。

- Chat、Embedding、Rerank 分开计数；实际失败和网络重试保留。
- 工具发现与实际工具执行分开；结构化修正不是网络重试。
- 模型用量取供应商返回值，缺失则未知；当前没有供应商实时账单或硬预算。
- 传输结果与业务状态分别展示：HTTP 2xx 并不代表数值校验通过或报告交付成功。
- 不记录或展示密钥、提示词、模型原始消息和隐式推理。

## 需要继续补齐的工程能力

当前以单机演示为目标。生产化仍需独立评估身份体系、持久会话、任务队列与取消、资源配额、限流、保留/删除策略、运维告警和多租户隔离。不得因本地权限回归通过而推导已满足企业安全要求。
