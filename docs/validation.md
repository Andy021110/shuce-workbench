# 验证与已知限制

## 证据如何区分

| 证据 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 单元/接口回归 | 指定边界、权限和异常处理符合断言 | 任意业务问题、外部用户收益 |
| 真实网页操作 | 对应界面和流程实际能操作 | 所有设备和所有输入均正确 |
| 真实模型执行 | 指定模型请求与工具确实发生 | 每次都成功、平均速度或稳定性 |
| 独立 SQL / CSV 核对 | 指定结果与另一套计算相符 | 原问题语义必然被完全理解 |
| Agent 模拟业务角色 | 在编排情境中可复现的卡点 | 外部真实用户反馈、频率、情绪和商业收益 |
