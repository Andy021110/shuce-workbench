# 扩展任务目录与覆盖

版本v12 · 2026-10-27。保留T-01至T-07任务主线，在其下扩展可验收子任务。本目录是任务与验收视图，不是新增功能已经交付的清单。依据为[本轮模拟角色实际试用](../evidence/v9-walkthrough.md)，未证明真实使用频率与业务收益。

## 目录使用方法

先选角色与场景，再走“触发 → 前置条件 → 动作 → 成功出口”。碰到异常转入下表对应分支；记录问题编号和证据。一次查询有数值不等于整个业务任务完成。主任务地图仍在[用户故事地图](02-用户故事地图.md)。

状态含义：可用＝本轮对应路径通过；部分可用＝数值或部分动作通过但有已知边界；已确认缺陷＝出现业务错误；安全阻断＝没有输出未经确认的结果；候选＝尚未实现；未实测＝本轮没有足够证据。不能将安全阻断计为业务成功。
