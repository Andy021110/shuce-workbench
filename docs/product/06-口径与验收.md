## 统计口径

目标为用户在本次复盘填写的值，当前不提供预算审批或预算版本管理。订单数、商品金额以实际不低于目标为达标；配送超时率以实际不高于上限为达标。差额始终为实际减目标，超时率差额使用百分点；仅正数的订单和金额目标计算完成率。未填写目标不判断达标，无可比较配送订单时不把超时率当作零。

单均商品金额使用同一下单月份、全部状态订单作分母，包含无商品明细订单。每单明细条数为商品表行数除以订单数，平均明细价格为商品金额除以商品明细条数。两者乘积等于单均商品金额；均值不直接相加。金额不含运费，不代表实收、净收入或利润。分解描述变化构成，不证明降价、促销或购买意愿等业务原因。


## 新增筛选口径

- 月度复盘按下单月份比较当前月和上月，金额BRL，原日期区间和快照保留。
- 状态和州限制订单范围；超时率在该范围内进一步限定已送达且日期齐全。
- 品类限制：订单数为包含所选品类的去重订单数；商品金额和商品明细条数只含所选品类的明细。因此不可将不同品类的订单数直接相加，商品金额可以按包含未分类的互斥品类加总。
- 目标仅针对填写时的月份和范围，不自动改成预算或套用于新范围。
- 自由问数继承已保存的结构化筛选；能识别的简单SQL等值或IN条件可记录为下次范围。v8起，服务端已验证且仅含可保留单值维度的群体，可在展示原问题及范围后确认继续；含无法保留的WHERE/HAVING、排除、OR、集合等额外条件仍在执行前阻断，要求重述全部条件；不自动猜测完整范围。
- 明确说“全部地区”“全部订单状态”“全部品类”或“清除筛选”时可取消相应继承限制；修改范围后必须展示新的范围。其他含糊修改需使用入口的范围控件。

## 验收清单

| 范围 | 验收条件 |
|---|---|
| 日期与筛选 | 当前/上月日期统一；结构化筛选由后端应用；SQL错误不能静默扩大范围 |
| 聚合 | 地区配送分子分母可加回总览；品类金额可加回总览；单均金额恒等式成立；均值不直接相加 |
| 零与空值 | 无订单均值留空；无配送分母超时率留空；未填目标不判断；零目标不计算完成率 |
| 权限 | 名称、报告编辑、范围选项及历史均按当前用户和授权数据源隔离 |
| 名称搜索 | 名称后端保存并恢复；空名称拒绝；搜索命中名称与原问题；无匹配有反馈 |
| 报告编辑 | 保留原始报告、数值和引用；人工结论/假设/动作分开；保存后恢复和导出；版本冲突保留草稿 |
| 解读失败 | 输出事实报告或保留原查询，给出可操作提示；不公开未验证正文作为事实 |
| 窄屏 | 范围、命名、编辑和搜索可操作；页面无横向溢出；表格内部滚动、首列固定、可选列与逐行卡片；阅读模式保留草稿 |

PDF仍使用系统打印入口；每轮只有实际验证后才能声称完成PDF导出验收。测试通过与真实用户价值验证分开记录。

## v6 新增验收边界

- 范围模板仅保存当前账号的州、状态、品类和口径版本1.0；每源最多20个。复用月份由当前表单确定，目标清空，不复制历史结果。当前单选表单遇到多选模板会明确拒绝应用，防止截断范围。
- 品类中文仅用于展示与搜索；SQL、CSV及保存的原始值不改动。新报告同时保留中文和源代码，旧报告保留原文。
- 模型结构化观察选择真实引用，后端渲染数值；引用不存在或数字无依据仍拒绝。单一维度数量仅在全部来源有同一明确筛选时允许，不能由单行预览推断总体。
- 可选图表来源或参数错误时不执行无效工具，保留通过校验的报告正文并提示图表缺失。
- 数据检查时间不是业务更新时间；空日期、无订单日和采集缺失分别处理。评论review_id重复提示核查更新记录，不自动等同订单重复。邮编地理坐标表未配置唯一标识，不判断重复。
- 本轮PDF入口保留系统打印方式；本批验证Markdown与CSV导出，不声称完成PDF文件版面复验。

最终网页复测还修正了图表标题可能与实际数值字段不符的问题：显示标题由实际指标和维度生成，金额按源单位、比率按百分比显示。长分析历史不再撑高外层页面；桌面与375px均保持外层滚动位置为零，正文在内容区域滚动。


## v9反例与v10验收补充

- 自然语言包含排除、否定改口、指标说明时，v9解析器曾存在UX-021/022/023缺陷。既有“后端强制范围”只保证执行被解析出的范围，不保证解析范围符合用户意图。
- 同一查询中，订单总数可以使用全部状态，超时率仅在指标内部限定可比较已送达样本；该条件不能提升为全局范围。
- 跨期老客定义为“当期去重买家中，在当期开始前买过的人”，需要独立历史窗口。全样本复购率是另一个指标，不可替换；v9该任务被安全阻断。
- 相对时间须先明确当前日期或用户选择的参照点与绝对区间。历史样本最大日期不自动等同今天；范围不覆盖时不得把最近历史月份当“上个月”。
- 问题、范围卡、SQL结果与文字矛盾，不能因文字里提示异常就按正确业务结果交付；validated=true不是任意业务语义证明。
- v9要求补验未保存报告编辑离开保护；已保存报告恢复与提问框草稿恢复不能替代此项。新增验收详见R-12至R-16。


## v10当前支持口径

明确正向与排除值由后端施加，范围卡及报告列出排除项；排除品类定义为剔除含该品类的整笔订单。全部状态总量不允许状态WHERE；配送样本用CASE/聚合FILTER单独定义。原问6512/854686.33与6351/393/6.19%网页核对通过。

老客标准路径仅一个明确下单月份、全部状态/地区/品类；本期买家按customer_unique_id去重，历史仅限样本中期初之前的记录；无本期买家时占比NULL。其他继承群体先要求清除并确认，不能直接套全历史复购率。

报告草稿按账号、数据源、报告存于本浏览器，基准修订号保留；切页/切源/刷新恢复已验收。导出只含后端已保存内容，不能把草稿提示当成已经保存。跨设备未支持。原始反例和完整验证见[v10验收](../evidence/v10-recovery.md)。
